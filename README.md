## `03` — Comment je conçois une solution

| Phase | Ce sur quoi je me concentre | Résultat |
|---|---|---|
| **01 · Découvrir** | Échanger avec les utilisatrices/utilisateurs et le client pour comprendre le vrai besoin | Un problème précis, qui vaut la peine d'être résolu |
| **02 · Concevoir** | Maquettes et wireframes sur Figma avant d'écrire la moindre ligne de code | De la clarté avant le code |
| **03 · Construire** | Implémentation lisible, modulaire, responsive | Un produit fiable et évolutif |
| **04 · Peaufiner** | Détails visuels, accessibilité, cohérence avec la maquette | Une expérience soignée de bout en bout |
| **05 · Améliorer** | Tests réguliers et itérations à partir des retours | Une qualité durable |
